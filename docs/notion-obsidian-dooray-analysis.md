# Notion · Obsidian · Dooray! 기본 동작 비교 (담다 기준)

2026-10-20 작성. "Doray"는 **NHN Dooray!(두레이)** 로 보았다.

- **[문서]**: 공식 도움말에서 확인한 내용.
- **[경험]**: 공식 문서에서 못 찾았고 일반적으로 알려진 실제 동작이라, 실기기 확인이 필요하다.
- 두레이 도움말은 JS로 그려져서 직접 읽지 못했다. 그래서 공식 소개 페이지, 마크다운 가이드, NHN Cloud 문서, 백과 문서를 바탕으로 했고, 두레이 부분은 상대적으로 얕다.

## 1. 페이지와 문서 구조

| 항목 | Notion | Obsidian | Dooray! |
|---|---|---|---|
| 계층 | 폴더 없이 페이지 안에 페이지 [문서] | vault 안의 실제 폴더와 .md 파일 | 개인 위키와 프로젝트 위키, 페이지 트리 [경험] |
| 사이드바 섹션 | 즐겨찾기, 팀스페이스, 공유, 개인. 섹션 제목을 클릭하면 접히고, 섹션마다 정렬과 표시 개수를 정한다 [문서] | 파일 탐색기와 북마크. 모두 접기/펼치기, 열린 파일 자동 표시, 정렬 [문서] | 프로젝트 목록 아래 업무, 드라이브, 위키 |
| 새 페이지 | 섹션 옆 `+`, 페이지 hover 후 `+`. 위치를 안 고르면 개인 섹션에 생긴다 [문서] | 새 노트 아이콘, `Ctrl+N`, 폴더 우클릭 [문서] | 위키 트리에서 하위 페이지 |
| 이동 | 끌어서 다른 페이지 위에 놓으면 중첩되고, 밖으로 빼면 풀린다. `⋮⋮` 메뉴의 Move to [문서] | 끌기, 우클릭 후 "Move file to…"(검색으로 고름) [문서] | 트리 끌기 [경험] |
| 이름 바꾸기 | 제목을 바로 편집 | **F2**. 이름을 바꾸면 링크가 자동으로 갱신된다 [문서] | 제목 편집 |
| 삭제 | 하위 페이지와 DB 항목까지 휴지통으로 간다. 30일 보관, 휴지통 안에서는 편집할 수 없다 [문서] | 시스템 휴지통, `.trash`, 영구 삭제 중에서 고른다 [문서] | 버전을 자동으로 남기고 복원할 수 있다 [문서] |
| 단축키 | `Ctrl+P`/`Ctrl+K` 검색 [문서] | `Ctrl+O` 빠른 전환, `Ctrl+P` 명령 팔레트 [경험] | - |
| 버전 기록 | 플랜별 7일, 30일, 90일 보관. 블록 일부만 복원할 수 있다 [문서] | 파일 복구, Sync 버전 기록 | 자동 버전과 복원 [문서] |

## 7. 두레이에서 배울 점

- **연결 중심**: 메일이나 메신저를 업무로 바로 바꾸고, `[`로 업무를 참조하고, 캘린더와 연동한다. 개인 앱에 적용하면 "어디서든 한 번에 담기"가 된다.
- **마크다운을 그대로**: 수식은 ` ```math ` 코드 펜스로 넣는다. 그래서 수식 편집이 그냥 텍스트라 깨지지 않는다.
- **발표 모드**: 위키를 버튼 하나로 슬라이드로 바꾼다.
- **버전 기록 기본 제공**: 누가 무엇을 바꿨는지 보여 주고 복원한다.
- **한국어 관례**: 짧은 명사형 용어를 쓴다. `#`, `-` 뒤에는 공백이 있어야 서식이 돼서, 한글 입력 중에 잘못 바뀌는 일을 막는다.

## 담다에 주는 시사점 (우선순위)

**P0: 틀리면 안 되는 기본**

1. 페이지 안 페이지 트리. 이동은 부모만 바꾼다. (Notion)
2. 섹션 제목을 누르면 접힌다. (Notion) → **1.0.13 반영**
3. 페이지 `+`로 하위 페이지를 만든다. (Notion)
4. 끌어서 중첩하거나 풀고, 놓을 위치를 표시한다. 별도로 "옮기기…"는 검색 선택. (Notion, Obsidian)
5. 삭제하면 하위까지 휴지통으로 간다. 30일 보관과 복원. (Notion) → 30일 정리는 아직 없음
6. `Ctrl+P`, `F2`, `Ctrl+N`, Delete. (Obsidian, Notion) → Ctrl+N은 아직 없음
7. 줄 처음의 Markdown 단축키는 공백을 쳤을 때만 바꾸고, 한글 조합 중에는 바꾸지 않는다. (Notion, Dooray) → **1.0.13 반영(키보드와 상관없이)**
8. `>`는 인용으로 한다(Markdown 호환). (Obsidian, Dooray) → 담다는 인용
9. 수식: `$$`와 `/수식`. 원문을 비우거나 Backspace를 두 번 누르면 삭제. (Notion, Obsidian) → **1.0.13 반영**
10. `Esc`로 블록 선택, `Ctrl+D` 복제, `Ctrl+Shift+↑↓` 이동. (Notion) → 아직 없음
11. `⋮⋮` 메뉴: 전환, 블록 링크, 복제, 이동, 삭제. (Notion) → 아직 없음(클릭하면 선택만 됨)
12. Android 뒤로가기는 이전 페이지로 가고 바로 종료하지 않는다. (Notion, Obsidian) → 1.0.12 반영
13. 모바일 키보드 툴바가 제대로 동작한다. (Notion, Obsidian) → **1.0.13 반영**
14. 모바일 길게 누르기 메뉴: 즐겨찾기, 이름 바꾸기, 복제, 이동, 링크 복사, 삭제. (Notion) → **1.0.13 반영(링크 복사 추가)**
15. 오프라인을 먼저 저장하고 동기화 상태를 표시한다. 충돌은 병합하거나 사본을 만든다. (Notion, Obsidian)
16. 옮긴 뒤 부모를 지워도 옮긴 페이지는 남는다. → 1.0.12 반영

**P1: 링크와 데이터베이스**

17. `[[`, `@` 멘션. 이름을 바꾸면 링크가 따라간다. (Obsidian, Notion)
18. 백링크 수 표시. 링크된 언급과 링크 안 된 언급을 구분한다. (Notion, Obsidian)
19. 블록 링크, `[[페이지#제목]]`. (Obsidian, Notion)
20. 유형을 바꿀 때 사라질 값이 있으면 경고하고, 지운 속성은 복원할 수 있게 한다. (Notion) → 경고와 복원은 아직 없음
21. 보드 카드 순서와 정렬 해제 확인. (Notion) → 1.0.3 반영
22. Relation과 rollup. (Notion) → 담다는 `lookup`으로 대신함
23. 복제했을 때 내부 DB와 relation 규칙. (Notion) → 1.0.10 반영(열·보기 복사)

**P2: 캡처와 부가 기능**

24. 공유할 때 대상 페이지를 고른다. (Notion)
25. 위젯: 새 노트, 페이지 열기, 즐겨찾기, 검색. 크기 조절. (Obsidian, Notion) → 크기 조절 예정
26. 버전 기록과 일부 복원. (Notion, Dooray)
27. 발표 모드. (Dooray)
28. 모바일 툴바를 사용자가 구성한다. (Obsidian)
