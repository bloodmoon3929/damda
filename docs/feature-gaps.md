# 나무에 부족한 기능 (Notion · Obsidian 대비)

2026-10-21 기준(1.0.14). 근거는 `notion-obsidian-dooray-analysis.md`의 공식 문서 조사와 나무 코드에서 실제로 확인한 기능 목록이다. REA로 앱을 직접 분석하지는 못했다(이 PC에 Notion·Obsidian 데스크톱 앱이 없고, REA MCP가 Claude Code에 등록되지 않음).

## 이미 있는 것 (비교 기준)

- **페이지**: 페이지 트리, 미정리/개인 페이지 섹션(접기), 즐겨찾기, 템플릿, 휴지통·되돌리기, 복제(DB 포함), 옮기기, 링크 복사.
- **편집**: 줄 처음 Markdown 단축키(키보드와 상관없이), `/` 명령(PC·폰), 표, 코드 블록(실행), 수식(블록·인라인), 이미지·파일·영상, 사진 보관함, 블록 끌어 옮기기, 블록 그대로 복사·붙여넣기.
- **링크**: `[[`·`@` 페이지 멘션, 백링크, 전체·로컬 그래프.
- **데이터베이스**: 표·보드·목록·캘린더·갤러리·타임라인·지도 보기, 수식, 자동 채우기, `lookup`, 계산 줄, 필터·정렬, 카드 순서, 유형 바꾸기, 오른쪽 클릭 메뉴.
- **가져오기·내보내기**: Markdown 가져오기·내보내기, Notion·Obsidian 가져오기.
- **동기화**: 자체 서버, 변경 기록, 블록 복원.
- **캡처**: 공유 시트, YouTube 페이지, 메모 위젯(1~5칸), 빠른 메모.
- **기타**: 검색(Ctrl+P), 단축키(Delete, F2), 뒤로가기 기록, 자료실·로컬 자료실.

## 부족한 것, 우선순위별

### P0: 매일 쓰는 기본인데 없음

| 기능 | 어디서 | 설명 |
|---|---|---|
| **블록 메뉴 `⋮⋮`** | Notion | 손잡이를 누르면 메뉴: 다른 블록으로 바꾸기, 색, 블록 링크 복사, 복제, 옮기기, 삭제. 지금은 선택만 된다. |
| **블록 단축키** | Notion | `Esc` 블록 선택, `Ctrl+D` 복제, `Ctrl+Shift+↑↓` 위아래 이동, `Tab`/`Shift+Tab`의 일관된 동작. |
| **새 페이지 `Ctrl+N`** | Obsidian, Notion | 단축키로 바로 새 페이지. |
| **토글 블록** | Notion | 접었다 펴는 블록. Notion 가져오기의 토글도 지금은 펼친 글로 들어온다. |
| **콜아웃** | Notion, Obsidian(`> [!note]`) | 아이콘과 배경이 있는 강조 상자. |
| **페이지 안 찾기·바꾸기 `Ctrl+F`** | 둘 다 | 지금은 전체 검색만 있다. |
| **목차(제목 개요)** | Obsidian 개요 창, Notion 목차 블록 | 긴 글에서 제목으로 이동. |
| **휴지통 30일 자동 정리** | Notion | 지금은 직접 비워야 한다. |

### P1: 노트 연결과 데이터베이스

| 기능 | 어디서 | 설명 |
|---|---|---|
| **블록 링크, `[[페이지#제목]]`** | 둘 다 | 페이지 안의 특정 블록이나 제목으로 가는 링크(계획만 있음). |
| **연결 안 된 언급 추천** | Obsidian | 같은 이름이 있으면 연결을 *제안*만 한다(사용자 결정: 자동 연결 금지). |
| **태그 `#태그`와 태그 목록** | Obsidian | 글 안의 태그로 모아 보기. |
| **데일리 노트** | Obsidian | 오늘 날짜 페이지를 한 번에 연다. 미정리와 같이 쓰기 좋다. |
| **Relation / Rollup** | Notion | 다른 DB의 항목을 직접 연결한다. 지금은 `lookup`(이름으로 찾기)이 대신한다. |
| **만든·고친 시각 속성, 상태(Status) 속성** | Notion | 자동으로 채워지는 시각, 할 일·진행·완료 그룹. |
| **여러 정렬 기준, 하위 그룹** | Notion | 지금은 정렬 하나, 그룹 하나만 된다. |
| **유형 바꾸기 경고·지운 속성 복원** | Notion | 바꾸면 사라질 값을 미리 알려 준다. |
| **링크 미리보기(북마크 카드)** | Notion | URL을 붙여넣으면 제목·그림 카드로 보여 준다. |
| **페이지 커버 이미지** | Notion | 페이지 맨 위 큰 그림. |

## 다음에 하면 좋은 순서 (제안)

1. 블록 메뉴 `⋮⋮` + 블록 단축키(`Esc`, `Ctrl+D`, `Ctrl+Shift+↑↓`) + `Ctrl+N`
2. 토글·콜아웃·목차 블록 (Notion 가져오기 품질도 같이 좋아짐)
3. 페이지 안 찾기·바꾸기
4. 데일리 노트 + 태그
5. 블록 링크·`[[페이지#제목]]`
